Desafio SQL — Análise de Dados

=> Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio de SQL, utilizando
o dataset público da Olist.

A ideia foi colocar em prática os aprendizados adquiridos na plataforma
de cursos da Growdev, como parte da fase do processo seletivo — 2ª Edição/2026 —
com foco em SQL e na resolução de perguntas de negócio que podemos
encontrar no dia a dia de uma empresa.

Durante o desafio, utilizei o PostgreSQL através do pgAdmin 4.

---

=> Objetivo

O objetivo principal foi utilizar SQL para transformar os dados do
*Brazilian E-Commerce Public Dataset by Olist* em informações que
possam ajudar na análise do negócio.

Entre as análises realizadas estão:

- comportamento e gastos dos clientes;
- pedidos e entregas;
- produtos e categorias;
- vendedores;
- pagamentos;
- avaliações;
- identificação de padrões e situações relevantes nos dados.

---

=> Ferramentas utilizadas

- PostgreSQL
- pgAdmin 4
- SQL
